# 0.3 الكينماتيكا والتحكم

الكينماتيكا الأمامية والعكسية، المصفوفة اليعقوبية، منظم PD، المعاوقة (impedance)، والأفق المتحرك. يوضح لماذا قد تخطئ شبكة عصبية تعلمت الكينماتيكا بنصف متر.

## الأقسام
1. زوايا المفاصل ووضعية الماسك
2. أين تتحرك الذراع بسهولة
3. شبكة عصبية تتعلم الكينماتيكا
4. المنظم: نابض ومخمّد
5. المعاوقة: بأي قوة نضغط
6. الأفق المتحرك
7. من ينفذ أوامر الشبكة
8. ثمانية أسئلة عن المفاهيم الخاطئة
9. خلاصة الدرس

## كيف تفتح الدرس
افتح `index.html` في المتصفح مباشرة (يعمل بدون سيرفر وبدون تثبيت). المختبرات داخل الدرس تعمل بالكامل في المتصفح: الشبكات العصبية الصغيرة تتدرب أمامك.
