# 0.2 تشريح الروبوت: المحركات والمستشعرات

درجات الحرية والمحركات والمستشعرات. يشرح لماذا تحسم نسبة علبة التروس نتيجة الاصطدام، وكيف تتعلم شبكة صغيرة نموذج المحرك من البيانات.

## الأقسام
1. ماذا ترى السياسة وبماذا تتحكم
2. المفصل درجة حرية واحدة
3. علبة التروس والصدمة
4. ست طرق لتحريك مفصل
5. ما يعرفه الروبوت عن نفسه وعن العالم
6. سلّم الترددات
7. نموذج المحرك من البيانات
8. ثمانية أسئلة عن المفاهيم الخاطئة
9. خلاصة الدرس

## كيف تفتح الدرس
افتح `index.html` في المتصفح مباشرة (يعمل بدون سيرفر وبدون تثبيت). المختبرات داخل الدرس تعمل بالكامل في المتصفح: الشبكات العصبية الصغيرة تتدرب أمامك.
