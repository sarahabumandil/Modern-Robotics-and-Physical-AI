# 0.4 تقدير الحالة والتخطيط

مرشح كالمان، مرشح الجسيمات، شبكة الإشغال وSLAM، ثم خوارزميات Dijkstra وA* وRRT وRRT*. خمسة مختبرات تفاعلية بمهام: ضبط ضجيج المرشح، مسألة الروبوت المخطوف، تشوه الخريطة من أخطاء العدّاد، والممر الضيق الذي يبطئ RRT.

## الأقسام
1. أين آدا وإلى أين تتجه
2. حساس مشوش ومرشح كالمان
3. أين آدا: مرشح الجسيمات
4. خريطة الليدار وSLAM
5. Dijkstra وA* على خريطة واحدة
6. لماذا لا تصلح الشبكة المنتظمة للذراع
7. RRT وRRT*: الأشجار العشوائية
8. كيف تعيش هذه الطرق اليوم
9. ثمانية أسئلة عن المفاهيم الخاطئة
10. خلاصة الدرس

## كيف تفتح الدرس
افتح `index.html` في المتصفح مباشرة (يعمل بدون سيرفر وبدون تثبيت). المختبرات داخل الدرس تعمل بالكامل في المتصفح: الشبكات العصبية الصغيرة تتدرب أمامك.
